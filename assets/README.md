# Marcel identity assets

These private application resources are reproducibly generated by
`scripts/build_identity_assets.py`.

- Iosevka 34.8.0: regular and semibold TTF faces subset to
  `U+0000-024F,U+0370-052F,U+2000-206F,U+20A0-20CF,U+2190-22FF,U+2500-26FF,U+FB00-FB06` and renamed to `Marcel Iosevka`. Licensed under SIL OFL-1.1.
  Source: https://github.com/be5invis/Iosevka/releases/download/v34.8.0/PkgTTF-Iosevka-34.8.0.zip
- Nordzy 1.8.7: twenty unmodified semantic SVG icons selected from
  the upstream theme. Licensed under GPL-3.0-only. Source: https://github.com/alvatip/Nordzy-icon/archive/refs/tags/1.8.7.tar.gz

The font is embedded in Marcel rather than installed in the user's font
registry. The icons form a private fallback and are not installed as a
system-wide freedesktop theme. Source archive hashes are pinned in the
generator.

The Marcel application icon under `icons/hicolor` is original project artwork.
Its three-pane browser mark highlights the persistent preview pane using the
default Nord identity palette. The SVG is the source of truth; raster hicolor
sizes are generated from it.
