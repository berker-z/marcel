# Sprint 28: Closing the review

**Status:** Implemented. The quality gate is green at 392 tests (from 305),
including `private_session_bus_integration` run outside the sandbox.

## Goal

[`docs/review-2026-09-18.md`](../review-2026-09-18.md) read the whole tree
before the v0.1.0 tag and came back with four things that would embarrass the
tag, about forty that should not ship, and a documentation set that had
drifted from the code. This sprint closes all of it except the two structural
items the review put in 0.2 (the `Location` enum and the preview pane as its
own entity), which stay where the review left them.

The review's own verdict held up under scrutiny with two corrections. Its
ffmpeg finding (that a playlist named `clip.mp4` would make the thumbnailer
open HTTP connections) does not reproduce: ffmpeg refuses to probe HLS under a
foreign extension, and the `file` protocol already whitelists only
`file,crypto,data` for nested opens. The flag went in anyway as belt and
braces, with a comment saying so. And the picker-title finding was worse than
"plausible": GPUI marshals through the system libwayland, which aborts the
process on a request over 4 KiB, so any sandboxed application could kill every
Marcel window with one `OpenFile` call.

## How it was run

Nine agents, each in its own git worktree with a disjoint set of files, all
based on `9de230c`. Filesystem work split into archive, copy and transfer, and
trash, delete, and permissions. Desktop and D-Bus was one agent; image memory
and thumbnails another; audio, media, and the subprocess builder a third.
Browse performance, app code quality, and documentation rounded it out. Each
reported the edits it needed outside its ownership, and those landed as glue
commits after the merges: the two-stage waveform wired into `app/preview.rs`,
every spawn site on `tool::command()`, copy staging on the shared
boot-stamped prefix, the filter field kept in step from `begin_listing`.

One agent was stopped mid-run with its work uncommitted; the diff was taken
over by hand and finished on master. One lesson cost real time and is now in
`CLAUDE.md`: a `CARGO_TARGET_DIR` shared across worktrees hands agents each
other's test binaries.

## What was built

### Filesystem

Copy reads every source through a descriptor. The walker holds one `openat`
directory handle per level, each entry is pinned with `O_PATH|O_NOFOLLOW`
before it is opened, and the open descriptor's device, inode, and type are
compared with what the walker decided on. A FIFO swapped in for a file fails
at once instead of blocking `open(2)` forever (which, through the one
application-wide operation lock, used to refuse every later operation until
restart). The self-containment check compares identities up the destination's
ancestors rather than path prefixes, so a bind mount no longer defeats it.
Staged directories are fsynced before the publishing rename and the
destination's parent after it; measured on ext4, batching the syncs keeps a
thousand-file copy within noise.

Deletion walks the quarantine with `openat(O_DIRECTORY|O_NOFOLLOW)` and
`unlinkat`, re-checking each level against the plan, and holds at most three
descriptors regardless of depth. Permission changes open `O_PATH|O_NOFOLLOW`,
refuse a symlink, and `chmod` through `/proc/self/fd`; rustix's `chmodat`
returns `EOPNOTSUPP` for `AT_SYMLINK_NOFOLLOW` on Linux, and this is what
glibc itself does.

Trash predicts the directory the `trash` crate will pick (home Trash or the
mount's `.Trash-<uid>`, mirroring its rules) and refuses when the source is on
a different device, using the wording moves already use; the crate's `EXDEV`
path is a lossy copy whose undo could never work. Restore now follows a
symlinked original parent into the directory it names, verifying that
directory's identity before the rename. A new home Trash is 0700.

Transfers that lose their own undo (ledger overflow, a move that cannot be
reversed) release their replacement quarantine immediately instead of
recording it; undo after such a transfer used to fail with `EEXIST` and
promote every original to `.marcel-recovered-*`.

7-Zip gets `-spd` on every invocation, so `*.txt` is a file called `*.txt`.
Verified against the store's 7zz 26.02: without it, `a -- '*.txt'` archived
four files. The listing preflight reads the POSIX type character from
`Attributes` and refuses links, pipes, devices, and sockets in zip and 7z as
well as tar, with real fixtures generated by 7zz. `archive_stem` never yields
a name `validate_entry_os_name` would refuse (`..zip` extracts into
`Archive/`), a single top-level entry with a reserved name is refused, and a
multi-entry extraction publishes a normally-moded folder rather than the 0700
tempdir. Archive staging carries `<boot>-<pid>-<seq>` like replacement
quarantines, copy staging adopts the same prefix, and the sweep reclaims
either kind once its owner is dead or the boot has changed. Staging from
older builds, which has no owner in its name, is shown so it can be deleted.

### Desktop

The portal title is bounded at 1 KiB. Bus activation is recognised from
Marcel's own three transient unit names, not any `dbus-*.service` cgroup, and
a bus-activated start that hears nothing within three seconds opens a window
at the working directory. The forwarding connection has a ten-second method
timeout and falls back to a standalone window. A duplicate request handle is
`InvalidArgs` rather than a stale dialog. `SaveFiles` rejects a request whose
URIs and names would misalign. `--help`, `--version`, and `--` work; an
unknown option exits 2; a folder named `notes:today` is a folder. The bus
reconnects after a disconnect, ten attempts a second apart, and reports if it
cannot. `FileManager1` and `Application` calls are rate-limited per sender.
`xdg-terminal-exec` is handed `--dir=` only when the launcher script mentions
the option, since older releases treat the first argument as the command.

Every child process goes through `preview::tool::command()`: `LD_LIBRARY_PATH`
removed, stdin null, its own process group. ffmpeg and ffprobe add
`-protocol_whitelist file,crypto,data`.

### Performance

`BoundedImageCache` implements GPUI's `ImageCache` with a byte ledger and LRU
eviction that calls `drop_image`, wrapping the browser at 64 MiB and the
preview pane at 128 MiB. Decoded previews, cover art, and posters are
`RenderImage`s outside any cache, so `PreviewState` queues them for release
when superseded and drains the queue at the top of the next draw. GPUI's
default retained every `img(path)` for the life of the process; a hundred PDF
pages was close to a gigabyte.

Audio previews publish tags, cover, and player at once; the waveform is a
second ticketed job that patches the preview and honours cancellation between
packets. The spectrum and waveform are one `canvas` each with a quad per bar.
Thumbnail work takes a per-listing cancel flag that reaches ffmpeg.
`ensure_thumbnails` is memoised on the visible window. The folder preview
stops at a thousand entries and counts as it streams.

Directory loads carry a cancel flag the walker checks; batches after the
first coalesce on a 32 ms timer; `reconcile_selection` returns early with an
empty selection and no filter; `SelectionModel::retain` takes borrowed paths.
A refresh (the menu's or the watcher's) stages the new listing and swaps it in
at `Done`, keeping entries, selection, filter, and scroll. Rescans of one
folder are spaced 1.5 seconds apart and the revalidation cap is 65,536 paths.
Icon sources are discovered once per process and the cache is keyed without
allocating. `command_enabled(OpenTerminal)` no longer stats the folder.

### Code quality

`state.conf` that cannot be read is reported when a window opens and never
written back, using the bookmark store's `read_only` pattern. Config files
over 1 MiB are refused. Move To filters the Trash out of its shortcuts,
reads folder lists off the UI thread with a ticket, and shares the breadcrumb
bar with the location bar. `names.rs` holds `select_stem`, `rename_stem_end`,
and `display_path_name`, so `operations` no longer reaches into `app`. The
filter field is written wherever the query changes rather than reconciled in
`render()`. `browse/` is GPUI-free as its module doc claims. `browse`,
`fsops`, and `preview` are `pub(crate)`, so the gate now sees unused items;
the `Added` and `Renamed` directory events, which nothing produced, are gone.
`Cargo.toml` drops the `target_os` table in favour of a `compile_error!`.

### Release and documentation

The package installs `LICENSE` and `THIRD_PARTY_NOTICES.md`. The notices
point at the files that exist after the Sprint 24 restructure and gain a
Symphonia section and a sentence about the Nordzy icons being read at runtime.
The AppStream release is dated to the release commit and `check_version.sh`
fails a tag whose newest release predates `HEAD`. CI passes the tag name to
`check_version.sh`, has a `permissions:` block, pins actions to SHAs, and sets
`MARCEL_TEST_REQUIRE_7ZZ=1` so archive tests fail rather than skip without
7zz. `marcel.portal` drops the deprecated `UseIn=`; the compat desktop entry
drops its MIME type. `SECURITY.md` and `CONTRIBUTING.md` exist. The README,
CHANGELOG, `interaction-model.md`, `file-chooser-portal.md`, `release.md`,
`AGENTS.md`, and `CLAUDE.md` say what the code does.

## Not built

The `Location` enum and the preview pane as its own entity, per the review's
0.2 placement. A fresh screenshot; the one in `docs/screenshots/` is from
August. `openat2(RESOLVE_BENEATH)` for the copy walker, which would hold one
descriptor instead of one per level but needs kernel 5.6 and upsets seccomp
profiles; the per-level walk fails with `EMFILE` past the soft descriptor
limit on a tree deeper than about a thousand levels rather than escaping the
guard. Entries inside an extracted archive whose names look like this boot's
dead-owner staging would be swept on the next visit; nothing validates nested
names against the `.marcel-` rule.
